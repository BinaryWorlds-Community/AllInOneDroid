# all_in_one_Droid

Feature Idea:

F1:: Storage Management:
- Able to maintain (add/edit/delete) items into a Storage

F2:: Cooking Book:
- Able to maintain (Add/edit/delete)
- Add new recipes via manual type into
- Add ingredient list, via camera screen
- import from other file formats / websites
- Filterable

F3:: Weekly Lunch Planner
- plan week ahead with recipes from cooking book
- filter accordingly
- get a "proposal" like : 3x meat 3x veg 1 idc
  based on meal rating, last time cooked etc
  
F4:: Shopping assistant
- based on weekly lunch planner & current Storage count
- calculate ingredient need
- create shopping list

F5:: Utility
- shareable with others via invite link
- near real time sync
- don't burn battery life
